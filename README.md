# Vanjo's BIG Emotes
# Twitch & Kick support

Now includes a settings popup with a live emote scale slider.

## Install Folder

1. Open Chrome
2. Go to chrome://extensions
3. Enable Developer Mode
4. Click Load unpacked
5. Select this folder

## OR Install CFX

1. Open Chrome
2. Go to chrome://extensions
3. Enable Developer Mode
4. Drag the .csx file into the extensions window
5. Refresh Twitch

## Usage

Click the extension icon and adjust the slider. Refresh (F5).
